# Synthetic Engineering Onboarding Policy
*Notice: This is synthetic challenge data for OnboardFlow AI demonstration.*

## Code Repository and Version Control
- All software engineers require GitHub Enterprise organization invitations and team assignments based on repository ownership.
- Engineers must configure GPG/SSH commit signing keys before pushing code to protected branches (`main`, `release/*`).
- Prerequisite: Corporate email and GitHub identity must be bound to corporate Entra SSO.

## Cloud Sandbox & Development Environments
- IT and Engineering Operations provision isolated cloud sandbox subscriptions (Azure Subscription / AWS Dev Account) with cost budget ceilings.
- Access to staging Kubernetes clusters and Datadog observability dashboards is granted upon completion of the security training.

## Engineering Manager 1:1 and Technical Ramp-up
- Engineering Managers must schedule a 45-minute technical ramp-up 1:1 on Day 1 to assign an onboarding buddy, review architecture docs, and assign the first good-first-issue starter bug.
